# 真机测试计划

## 环境准备

- 硬件：ESP32-S3-EYE 开发板 + 外接加速度计(ADXL345) + 扬声器模块(MAX98357A)
- 工具：串口终端(minicom)、WiFi 网络、飞书 Webhook 地址
- 固件：编译 `esp32s3-eye_defconfig` 生成的固件

## 测试步骤

### 一、固件烧录

- [ ] 1.1 编译固件：`./build.sh esp32s3-eye`（或等效命令），确认无编译错误
- [ ] 1.2 使用 esptool 烧录固件到 ESP32-S3-EYE 开发板
- [ ] 1.3 烧录完成后按 Reset 按钮重启

### 二、串口验证启动

- [ ] 2.1 打开串口终端（115200 baud），确认 openvela 启动成功
- [ ] 2.2 确认看到 `[fall_detect_app] Starting AI Agent for fall detection...` 日志
- [ ] 2.3 确认看到 `Registered skill: fall-detect`、`Registered skill: fall-patrol`、`Registered skill: voice-help` 三条日志
- [ ] 2.4 确认看到 `All 3 skills registered. Entering main loop.` 日志
- [ ] 2.5 确认加速度计 I2C 设备初始化成功（无 I2C 错误日志）

### 三、手动触发加速度计阈值

- [ ] 3.1 在串口中执行命令查看加速度计实时数据：`cat /dev/accel0`（或对应设备节点）
- [ ] 3.2 手动摇晃/倾斜开发板，使 Z 轴加速度超过 ±3g 阈值
- [ ] 3.3 确认串口输出 `fall_detected` 或 `fall_suspected` 事件日志
- [ ] 3.4 确认去抖逻辑生效（500ms 内不重复触发）

### 四、确认摄像头拍照

- [ ] 4.1 跌倒事件触发后，确认串口输出 `photo_captured` 事件日志
- [ ] 4.2 确认摄像头 V4L2 设备被正确打开（无 `/dev/video0` 错误）
- [ ] 4.3 确认拍照数据被正确读取（日志中显示图片大小或 CRC）
- [ ] 4.4 如有 LCD 屏，确认照片预览正常显示

### 五、确认 Vision LLM 返回结果

- [ ] 5.1 确认 WiFi 已连接（`ifconfig` 或日志显示 IP 地址）
- [ ] 5.2 确认 HTTP 请求成功发送到 Vision LLM API（日志显示 HTTP 200）
- [ ] 5.3 确认 LLM 返回了场景分析结果（日志中显示分析文本）
- [ ] 5.4 确认 `llm_analysis_done` 事件被触发
- [ ] 5.5 异常场景：断开 WiFi，确认有重试机制和错误日志

### 六、确认飞书通知发送

- [ ] 6.1 确认 `feishu_notification_sent` 事件被触发
- [ ] 6.2 在飞书群/个人中收到包含图片和分析结果的消息卡片
- [ ] 6.3 确认消息内容包含：时间戳、传感器数据摘要、LLM 分析结果
- [ ] 6.4 异常场景：使用错误 Webhook，确认有错误日志输出

### 七、确认 TTS 语音播报

- [ ] 7.1 跌倒事件后，确认扬声器播放语音提示（"检测到跌倒，是否需要帮助？"）
- [ ] 7.2 确认 I2S 音频输出无杂音/断音
- [ ] 7.3 测试 5 秒超时：不说话，确认超时后升级为紧急状态
- [ ] 7.4 测试正常回复：对麦克风说"没事"，确认报警取消
- [ ] 7.5 测试紧急回复：对麦克风说"救命"，确认紧急状态触发

### 八、集成测试

- [ ] 8.1 完整流程：触发跌倒 → 拍照 → LLM 分析 → 飞书通知 → TTS 播报，全流程 < 10 秒
- [ ] 8.2 多次触发：连续触发 3 次跌倒事件，确认无内存泄漏或崩溃
- [ ] 8.3 定时巡检：等待 CONFIG_AI_AGENT_CRON 定时器触发，确认自动巡检执行
- [ ] 8.4 重启恢复：重启设备后确认所有 Skill 重新注册并正常工作

## 故障排除

| 现象               | 可能原因           | 排查方法           |
| ------------------ | ------------------ | ------------------ |
| 串口无输出         | 波特率错误         | 确认 115200 baud   |
| I2C 设备未找到     | 接线错误/设备树    | 检查硬件连接       |
| WiFi 连接失败      | SSID/密码错误      | 检查 defconfig 配置|
| 摄像头打开失败     | 设备节点路径错误   | `ls /dev/video*`   |
| 飞书通知未收到     | Webhook 地址错误   | curl 测试 Webhook  |
| TTS 无声           | I2S 配置错误       | 检查 I2S 引脚配置  |
