## 数据流详解

### 1. 跌倒检测流程（fall-detect）

```
加速度计(ADXL345)
      │
      ▼
  I2C 驱动读取原始数据
      │
      ▼
  Sensor HAL → accel_read Tool
      │
      ▼
  fall-detect Skill 计算加速度向量幅值
      │
      ├── 未超阈值 → 继续监测（循环）
      │
      └── 超过阈值(±3g) → 触发 fall_detected 事件
                │
                ├──→ fall-patrol Skill（拍照分析通知）
                └──→ voice-help Skill（语音播报确认）
```

### 2. 巡检上报流程（fall-patrol）

```
fall_detected 事件
      │
      ▼
  cam_snap Tool → V4L2 → OV2640 拍照
      │
      ▼
  llm_query Tool → HTTP POST → Vision LLM API
      │                         (返回场景分析结果)
      ▼
  feishu_tx Tool → HTTP POST → 飞书 Webhook
      │                         (推送图片+分析+传感器数据)
      ▼
  feishu_notification_sent 事件
```

### 3. 语音确认流程（voice-help）

```
fall_detected 事件
      │
      ▼
  TTS 引擎生成语音
      │
      ▼
  I2S 驱动 → MAX98357A 扬声器播放
      │
      ▼
  I2S 驱动 ← INMP441 麦克风录音（5s 超时）
      │
      ├── 无回复 / 听不清 → emergency_escalated（紧急上报）
      ├── 回复"没事" → 取消报警
      └── 回复"救命" → emergency_escalated（紧急上报）
```

## 输出层汇总

| 输出通道 | 接口        | 目标              | 触发 Skill  |
| -------- | ----------- | ----------------- | ----------- |
| 飞书通知 | HTTP POST   | 飞书群/个人       | fall-patrol |
| TTS 语音 | I2S 输出    | 扬声器            | voice-help  |
| 串口日志 | UART        | 开发者终端        | 全部        |
| 震动马达 | GPIO/PWM    | 用户身体反馈      | voice-help  |
