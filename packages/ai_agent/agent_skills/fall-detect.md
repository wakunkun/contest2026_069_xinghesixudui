# fall-detect Skill

## 概述

跌倒检测 Skill，通过加速度计数据实时监测用户姿态，当检测到跌倒事件时触发报警流程。

## 触发条件

- 加速度计 Z 轴加速度超过阈值（默认 ±3g）
- 姿态角变化速率超过设定值
- 静止时间超过 N 秒（疑似失去意识）

## 数据流

1. 读取加速度计传感器数据（I2C 接口）
2. 计算加速度向量幅值和姿态角
3. 与阈值比较，判定是否跌倒
4. 触发后续动作：拍照（fall-patrol）+ 通知（voice-help）

## 配置参数

| 参数             | 默认值 | 说明             |
| ---------------- | ------ | ---------------- |
| ACCEL_THRESHOLD  | 3.0g   | 加速度触发阈值   |
| STILL_TIMEOUT_S  | 10     | 静止超时秒数     |
| DEBOUNCE_MS      | 500    | 去抖时间窗口     |

## 输出事件

- `fall_detected`：跌倒事件确认，携带时间戳和传感器快照
- `fall_suspected`：疑似跌倒，等待二次确认
